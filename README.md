# FNAF6-3D

A 3D fan recreation of *Five Nights at Freddy's 6: Freddy Fazbear's Pizzeria Simulator* built with Unity and C#.

## Overview

This project reimagines the office-survival gameplay of FNAF 6 in a real-time 3D environment. Players complete terminal tasks while monitoring side vents, managing heat and noise levels, and fending off animatronics using audio lures, motion detection, and a flashlight.

## Features

- **3D Office & Vent Environment:** Real-time 3D perspective with smooth transitions between the terminal and left/right ventilation shafts.
- **Animatronic AI:** State-driven movement, vent navigation, and escalating behavior patterns.
- **Survival Mechanics:** Terminal task progression, motion detector, audio lure system, silent ventilation, and flashlight checks.
- **Spatial Audio:** Directional audio cues for vent movement and proximity awareness.

## Tech Stack

- **Engine:** Unity *(e.g., Unity 2022.3 LTS)*
- **Language:** C#
- **Assets:** 3D character/environment models, custom shaders/materials, and spatial audio

## Getting Started

1. Clone the repository:
   ```bash
   git clone [https://github.com/Mach3tryhard/FNAF6-3D.git](https://github.com/Mach3tryhard/FNAF6-3D.git)
   ```
2. Open **Unity Hub** and click **Add** → **Add project from disk**.
3. Select the cloned `FNAF6-3D` directory and open it in Unity.
4. Load the main scene in `Assets/Scenes/` and press **Play**.
